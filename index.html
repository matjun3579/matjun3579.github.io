BFS 최단 경로 체험

격자에 출발점과 도착점을 선택하고 벽을 추가한 뒤 최단 경로를 확인해 보세요.

출발점 도착점 벽 탐색한 칸 최단 경로
출발점과 도착점을 설정한 후 벽을 만들어 보세요.

알고리즘 안내

BFS란?

너비 우선 탐색입니다. 출발점에서 가까운 칸부터 차례로 살펴봅니다. 상하좌우로만 이동하고 이동 비용은 모두 1이므로 가장 먼저 도착점에 도달한 경로가 최단 경로입니다.

FIFO 큐

JavaScript 배열과 head 인덱스로 큐를 사용합니다. 칸은 큐의 뒤에 넣고 head 위치의 칸을 꺼냅니다.

방문 처리

칸을 큐에 넣는 순간 방문 표시를 합니다. 이를 통해 같은 칸을 중복해서 큐에 넣는 일을 막습니다.

경로 복원

각 칸에 방문하기 직전의 이전 칸을 저장합니다. 도착점에서 이전 칸을 따라 출발점까지 거꾸로 이동해 최단 경로를 복원합니다.

사용 방법
  1. 출발점과 도착점을 각각 한 번씩 선택합니다.
  2. 벽 만들기로 장애물을 추가하거나 벽 지우기로 제거합니다.
  3. 탐색 시작을 누르면 색상과 이동 횟수가 표시됩니다.
